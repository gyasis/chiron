How a NEW widget kind gets added

The path we just walked for the 10 universal widgets. The SAME path would add a new chart-xy widget for the Quant Trading lesson (or any other gap).

1

Schema

Add a Zod schema to widget-spec.ts describing the shape (fields, types, defaults, refinements). Register in the discriminated union + WIDGET_KINDS + the appropriate tier array.

lib/schemas/widget-spec.ts
commit 1 — schema only
2

Renderer

Write renderXxx(spec) that emits HTML matching the shell CSS classes. Register via registerRenderer('xxx', …) — overrides the Wave-2 throwing stub. Bake .btn classes into any control buttons.

lib/widget-renderer.ts
commit 2 — renderer + dispatch
3

Prompt + validator

Tell Stage-4 WHEN to emit it: edit 04a-chapter-write.md with per-domain "use when" guidance. Add a validator floor in validator.ts if certain content categories MUST emit it. Wire the new issue code into 03-validate-rubric.md.

prompts/04a, prompts/03, lib/validator.ts
commit 3 — prompts + validator
4

Reproducibility test

Add a case to scripts/test-graphiti-pipeline-repro.mjs (or a new repro script) — construct a spec, assert it parses, assert renderer output contains the expected CSS hooks. Run it; 100% pass before merge.

Next gap — chart-xy

What a chart-xy widget would need

For Quant Trading and the broader concepts domain, we need a line / scatter / candlestick chart. SVG-based for cheap render, optional hover tooltip, no heavy chart library. Schema sketch:

export const ChartXyWidgetSchema = z.object({
  type: z.literal('chart-xy'),
  id: z.string(),
  title: z.string().optional(),
  xLabel: z.string().optional(),
  yLabel: z.string().optional(),
  variant: z.enum(['line','scatter','bar','candlestick']),
  series: z.array(z.object({
    label: z.string(),
    color: z.string().optional(),         // CSS var preferred — e.g., 'var(--chiron-accent)'
    points: z.array(z.object({
      x: z.number(),                       // or ISO date string for time-series
      y: z.number(),
      ohlc: z.object({                     // only for candlestick
        open: z.number(), high: z.number(),
        low:  z.number(), close: z.number(),
      }).optional(),
    })),
  })).min(1),
  annotations: z.array(z.object({         // text labels at (x, y) — moving averages, dividers
    x: z.number(), y: z.number(), text: z.string(),
  })).optional(),
});

Steps to land it: same 4-step flow above. ~half a day end-to-end. Once committed, the Quant Trading lesson can use chart-xy instances for price series, P&L curves, distribution histograms, Sharpe-ratio rolling windows.
