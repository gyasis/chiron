What each domain has — after v1

Three domains, three widget rosters, one shared engine. After the feat/universal-widgets-v1 work, all three domains gained 9 universal engagement widgets while keeping every domain-locked primary assessment format unchanged. Below: side-by-side of what's available to each Stage-4 chapter writer per domain.

domain · code

Code

Audience: vibe coder — non-engineer who steers AI tools. Goal: read & understand code, not write it from scratch.

Locked primary — code-only quiz primitives

spot-the-bug

Marked-line code with a known buggy line; learner identifies it.

code-runner

Live Pyodide / native runtime — learner edits + runs code in the lesson.

mcq

Multiple-choice with per-distractor explanations (FR-021 variants).

true-false

Quick binary check.

mermaid

Architecture / data-flow diagrams.

Universal engagement (new — additive)

group-chat-animation

System dialog — agent ↔ tool, function ↔ caller, services on a bus.

e.g., demonstrating the entity_types lever as a 6-message dialog
flow-animation

Data flow, request lifecycle, build pipeline — animated walk between actors.

e.g., the 4-step Cascade Memory Protocol walk
glossary-tooltips

Inline tooltip on every CS jargon term on first mention.

REPL · JSON · namespace · entry point · PATH
why-care-callout

Practical-stakes lead-in: "this helps you steer AI better, debug faster, ship safer."

pattern-cards

Design patterns, refactor moves, anti-patterns — one card each.

step-cards

Numbered protocol — deployment sequence, debugging routine.

file-tree

Project structure / monorepo layout / storage paths.

permission-badge

Atomic cost / status pill — free / paid / hot / read.

layer-toggle

Two-axis comparison — local vs prod, sync vs async, axis A vs axis B.

Code-only (new — schema-gated)

code-english-translation

Side-by-side code lines + plain-English line-by-line, row-paired with 6-color tint.

The single biggest pedagogy lift for code lessons
domain · medicine

Medicine

Audience: med student / clinician — USMLE/AMBOSS pedagogy. Goal: pattern recognition + algorithmic clinical reasoning.

Locked primary — clinical assessment formats

mcq-clinical-vignette

AMBOSS template: clinical stem + labs + leading question + 5 options + per-distractor explanation.

Primary assessment — never replaced
agreement-matrix

Always / sometimes / never — clinical reasoning across multiple statements.

assertion-reason

"Both true and reason explains" / "both true but reason doesn't" — classic clinical reasoning format.

confidence-weighted

MCQ + ask the learner how confident they are. Calibration training.

slider-estimation

Lab-value range estimation / dose calculation tolerance.

boss

High-stakes culminating multi-step case at end of chapter.

pathway-diagram

Signal cascade, metabolic pathway — biochemistry-aware diagram.

chemical-reaction

mhchem rendering — drug metabolism, receptor binding.

molecule-2d

2D molecular structure.

forest-plot

Meta-analysis effect sizes — EBM literacy.

reactive-math

Interactive equation manipulation.

mathjax

Static rendered math.

Universal engagement (new — additive)

flow-animation

Differential-diagnosis algorithm walks. "Post-chest soreness? → check vitals → next exam." Branches as actors, active branch highlighted.

Universally valuable — terminology IS the curriculum

pattern-cards

Drug classes (e.g., 5 ACE-i + 2 ARBs), syndrome families, antibiotic spectra.

step-cards

ACLS bundle, sepsis-6, BLS steps — protocol reference.

file-tree

Anatomy hierarchy, taxonomic classification, body-system organization.

permission-badge

OTC / Rx / controlled / contraindicated — atomic regulatory cue.

layer-toggle

Acute vs chronic, primary vs differential, ambulatory vs inpatient.

domain · language

Language

Audience: solo language learner (Italian for v1; German deferred). Goal: production + comprehension via spaced retrieval and native exposure.

Locked primary — language practice formats

fill-blank

Single-token cloze with fuzzy-match (umlaut / accent normalization).

cloze

Sentence-level cloze — Anki-compatible.

matching-pair

Term ↔ definition / vocab ↔ translation pairing.

audio-tts

Gemini-voiced native-speaker audio — pronunciation + listening comprehension.

Primary mechanism for native-pronunciation exposure
match-madness

Multi-set retrieval-practice anchor — vocab / gender / prep / collocation / conjugation modes.

Canonical retrieval-practice anchor per PRD §4.10–4.12
language-flashcard-deck

Vocab card decks with verb / noun / idiom entries — SR-card ready.

conjugation (via match-madness mode)

Italian -are / -ere / -ire / -isco-ire families with ho/sono auxiliary.

Universal engagement (new — additive)

group-chat-animation

Native ↔ learner roleplay. "Here's how a Roman would say this." Each native bubble can reference an audio-tts id.

Single highest-value addition for language
flow-animation

Sentence construction order (SVO drift), verb conjugation reveal across pronouns, dependent-clause assembly.

glossary-tooltips

Every new vocabulary word on first mention. Tooltip = inline definition. This is the whole game.

why-care-callout

"You'll need this at the coffee bar / asking directions / negotiating a contract."

pattern-cards

Verb families (-are / -ere / -ire), irregular sets, preposition collocations, idiom clusters.

step-cards

Grammar rule sequences — "to form the subjunctive: 1... 2... 3..."

file-tree

Morphology trees, register hierarchies, dialect families.

permission-badge

Formal / informal / vulgar / regional — register pills inline on vocab.

layer-toggle

Formal (Lei) vs informal (tu), spoken vs written, present vs historical-present.
